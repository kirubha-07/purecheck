# PureCheck Power BI Dashboard

Analytics and reporting dashboards for PureCheck.

## Dashboards

- Risk Trends by City
- High-Risk Foods by State
- Adulterant Distribution
- Complaint Source Analysis
- Time Series Risk Evolution

## Data Connection

Connect to PostgreSQL `purecheck_db` database:
- Host: localhost
- Database: purecheck_db
- Tables: core_complaint, core_riskscore, core_livealert

## Usage

Open `.pbix` files in Power BI Desktop to view/modify dashboards.
